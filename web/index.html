     OxC3 HLSL syntax
    
    
    
  
    
    
    Standard HLSL plus a small set of [[oxc::…]] annotations, @-includes and type aliases —
      one source, both SPIR-V and DXIL. Stage and shader model live in the source (not the toolbar), so a single file can hold many
      entrypoints, each producing its own binaries.
    

    
    Entrypoint stage
    
    
    [shader("compute")]
      
    Preferred. DXC's shader annotation. Library types (lib_6_x):
        raygeneration · closesthit · anyhit · miss · intersection · callable · node — and it also accepts the
        standalone stages below. Required when [[oxc::uniforms]] is used (uniforms need a lib compile).
    
    
    [[oxc::stage("vertex")]]
      
    Standalone compilation per entrypoint: vertex · pixel · compute · geometry · hull · domain · mesh · task.
    
      
     Deprecated in favour of [shader] (kept for compatibility; each stage costs a full compile and can't use uniforms).
    

    
    Annotations
    
    
    [[oxc::model("6.8")]]
    Minimum shader model, per entrypoint (6.5 … 6.10). Repeat the annotation to compile the same entrypoint at multiple models; the runtime picks the highest available. __SHADER_TARGET_MAJOR/_MINOR distinguish them at compile time.
    
    
    [[oxc::extension("16BitTypes", "RayQuery")]]
    Required extensions — sets __OXC_EXT_<NAME>. Repeating the annotation makes one compile per set (e.g. with and without RayReorder); the runtime picks top to bottom.
    
      
    One of: F64I6416BitTypesAtomicI64AtomicF32AtomicF64SubgroupArithmeticSubgroupShuffleSubgroupOperationsRayQueryRayMicromapOpacityRayTriPositionRayMotionBlurRayReorderMultiviewComputeDerivPAQMeshTaskTexDerivWriteMSTextureBindlessUnboundArraySizeCoopVecCoopMatCoopFP8CoopVecTrainingDescriptorHeap
    
    
    [[oxc::defines("HAS_SHADOWS", "TAPS" = "4")]]
    Preprocessor defines, referenced as $NAME. Each annotation is one variant — a full extra HLSL compile, so prefer uniforms.
    
    
    [[oxc::uniforms(U32 x = 45, F32 y = 90.f)]]
    Spec constants (SPIR-V) / library exports (DXIL), referenced as $$x. Fossilized by linking after compile — much cheaper than defines. Types: (U/I/F)(8/16/32/64) or B1. Requires [shader].
    
    
    [[oxc::vendor("NV")]]
    Restrict a binary to vendors: NV · AMD · ARM · QCOM · INTC · IMGT · MSFT · APPL · SMSG · HWEI · GOGL · MESA. Absent = all. One annotation only (it never induces a compile per vendor).
    
    
    [[oxc::binary("spv", "dxil")]]
    Narrow which requested backends this entrypoint is emitted for (no extra compiles; ANDed with -compile-output and what the stage/extensions can express — workgraphs are DXIL-only, SubgroupArithmetic/Shuffle, AtomicF32/F64 and RayMotionBlur are SPIR-V-only, MeshTaskTexDeriv is DXIL-only).
    

    
    Includes
    
    
    #include "common.hlsli"
    Relative include, resolved from the file tree (roots act as -include-dir). Escaping the working directory is prohibited. Every resolved include lands in the oiSH with its CRC32C.
    
    
    #include "@types.hlsli"
    Builtin umbrella: portable type aliases (F32x4, U32x3, …) + _bind/_flat/PUSH_CONSTANT/UNKNOWN_FORMAT, and it pulls in the parts split out of it:
      @mat.hlsli (matrix helpers), @indirect.hlsli (indirect command structs), @fixed_point.hlsli. Include one directly to take only that part.
    
    
    #include "@resources.hlsli"
    Builtin umbrella: OxC3's bindless resource access (descriptor heaps, ResourceId helpers), pulling in @buffer.hlsli (typed bindless buffer loads/stores) and @appdata.hlsli (the per-frame app data buffer).
    
    
    #include "@extensions.hlsli"
    Umbrella pulling each enabled extension's helpers; or pick one:
      @extension.{CoopVec, CoopMat, RayReorder, RayTriPosition, RayMicromapOpacity, AtomicF32, AtomicF64}.hlsli.
    
      
    Built-in symbols show up in Symbols (oiSR) collapsed per include, the way shader reflect-symbols prints them; file data --includes expands them.
    

    
    Builtin defines
    
    
    __OXC__OXC_PREPROCESS__OXC_MAJOR__OXC_MINOR__OXC_PATCH__OXC_VERSION__OXC_EXT_<X>__OXC_EXT_RAYTRACING__SHADER_TARGET_MAJOR__SHADER_TARGET_MINOR
      
    During the __OXC_PREPROCESS pass all extensions are on but no uniforms/defines are set — guard with #ifdef.
    

    
    Type aliases (from @types.hlsli)
    
    
    Always available — scalar, x2/x3/x4 vectors, matrices xNxM (columns×rows, so HLSL float4x3 = F32x3x4):
    
      F32F32x4F32x4x4I32x3U32x4BoolBoolx4
    
    
    Under 16BitTypes: F16F16x4I16U16x4 · under F64/I64: F64x4U64I64x3
    

    
    Resource keywords & macros
    
    
    PUSH_CONSTANT MyCmd cmd;
    Root / push constants (SPIR-V [[vk::push_constant]], DXIL root CBV).
    
    
    UNKNOWN_FORMAT RWTexture2D<F32x4> o;
    Storage image without a declared format (SPIR-V image_format("unknown")).
    
    
    float2 uv : _bind(0);   _flat U32 id;
    _bind(x) → TEXCOORD##x semantic · _flat → nointerpolation. Non-SV semantics should stay TEXCOORD[n] for compact storage.
